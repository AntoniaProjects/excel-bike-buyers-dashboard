# Excel Bike Buyers Dashboard

## Project Overview

This project analyzes customer demographics and purchasing behavior using Microsoft Excel.

The objective was to identify factors influencing bicycle purchases and present the findings through an interactive dashboard.

## Dataset

The dataset contains customer information including:

* Gender
* Marital Status
* Income
* Education
* Occupation
* Age
* Region
* Commute Distance
* Bike Purchase Status

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Dashboard Design

## Process

### Data Cleaning

* Standardized categorical values
* Improved data readability
* Created age brackets
* Removed inconsistencies

### Data Analysis

Created Pivot Tables to analyze:

* Income vs Bike Purchases
* Age Groups vs Purchases
* Commute Distance vs Purchases
* Regional Differences

### Dashboard Creation

Built an interactive dashboard allowing users to filter results using slicers.

## Key Insights

* Customers with higher income were more likely to purchase bicycles.
* Middle-aged customers represented the largest buyer segment.
* Commute distance showed a measurable impact on purchase decisions.
